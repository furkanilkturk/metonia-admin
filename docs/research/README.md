# Ecosystem research

This directory records dated findings from authoritative primary sources for Svelte, SvelteKit, Remote Functions, the `sv` CLI, shadcn-svelte, Fluid UI, Bun, Deno, Zod, Drizzle, PostgreSQL, and Docker.

Every integration must state its verified support level (`stable`, `experimental`, `unsupported`, or `unknown`) and link to the source used to make that decision.
